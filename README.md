# Kingshot 전투 시뮬레이터 v1.0

Made by 주말이(933) × 베이컨(943) × 우유(582)

보병·기병·궁병 병력과 집결 영웅 조합을 넣으면 전투 결과(승패·손실·생존)를 계산하는 단일 HTML 페이지입니다.
`index.html` 하나로 동작하며 서버·빌드가 필요 없습니다.

## 반영된 것
- 병사 기본 수치: 게임 내 병영 순금 레벨표(T10 에이스 / T11 순금, TG0~8), T11 = T10 + 2
- TG 스킬(기댓값): 보병 흔들리지 않는 방패·불멸의 육신·밀집 진형/강철 수호, 기병 강습의 창·강철 방어·돌격·기습, 궁병 연사·포효하는 바람·순금의 바람·원거리 타격
- 집결 영웅: 집결장 3명(원정 스킬 3개 + 전용무기, 공격측 공성용 / 방어측 수성용) + 집결원 4명(첫 번째 원정 스킬). 같은 ID 합연산·다른 ID 곱연산, 확률형 기댓값, 병종 한정 스킬은 해당 병종에만 적용 (계산 체계: 우유(582), 데이터: kingshotdata.com)
- 전투 모델: v0.7 구조 — 라운드마다 공격×파괴 ÷ (상대 방어×체력) × √(병력×ArmyMin) ÷ 100, 보병→기병→궁병 순 타깃, 정수 사상자·소수 누적, 손실은 부상 35%·경상 65%
